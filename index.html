Noxi Outlier Finder

Find the videos that beat their own channel's normal views, and the topics those videos have in common.

Scan channels

Saved only in this browser and sent only to YouTube.

Use an @handle, a channel link or a UC channel ID. Add smaller channels too: their wins depend less on audience size.

Get a free API key
  1. Open Google Cloud Console and create a project.
  2. Open the YouTube Data API v3 page and click Enable.
  3. Open Credentials, click Create credentials, then API key.
  4. Edit the key. Under API restrictions, choose YouTube Data API v3. Under Application restrictions, choose Websites and add https://xplanxplanet.github.io/*.
  5. Paste the key above. You don't need to add a card for the free quota.

Outlier videos
