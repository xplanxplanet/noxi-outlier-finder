Noxi Outlier Finder

Compare niches, track new channels that are taking off, and find the videos and topics behind their growth.

YouTube API key

Saved only in this browser and sent only to YouTube.

  1. Open Google Cloud Console and create a project.
  2. Open the YouTube Data API v3 page and click Enable.
  3. Open Credentials, click Create credentials, then API key.
  4. Edit the key. Under API restrictions, choose YouTube Data API v3. Under Application restrictions, choose Websites and add https://xplanxplanet.github.io/*.
  5. Paste the key above. You don't need to add a card for the free quota.

Channels

Views per day uses the last 7 days once there are two daily snapshots. Until then it's the average since the channel was created. Tap a channel to check its style, because some reuse other people's clips.

Channels that stopped uploading

These channels stopped posting but may still get views, so their format could be worth trying. Views per day appears once a channel has two daily snapshots; until then it says "Not measured yet". Only channels in the database are included, so these are under 2 years old. Copy the format and topic, never the videos themselves.

Compare niches

Write each niche the way people search for it. Each one uses 1 of your 100 daily searches. To use your own RPM, add it after a bar, like animated finance | 8.

Niche scores

Score out of 100. It weighs how many views the top videos get (35%), how often small channels reach the top (25%), how often new channels do (25%) and estimated RPM (15%).

Who's winning in each niche

RPM is a rough guess, in US dollars, of what YouTube pays creators per 1,000 views for this kind of content. Real RPM depends on viewers' countries, video length and the time of year. Each niche is judged on YouTube's 50 most-viewed matching videos from the period, so this shows the top of a niche, not all of it.
